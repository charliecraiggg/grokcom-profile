# 嘉玮个人作品集 · 微信小程序

在微信开发者工具中导入本目录（AppID 已写入项目配置），使用管理员或有开发权限的微信扫码登录。工程无需安装依赖。

2026 年 11 月 23 日，开发者工具编译通过，并确认开发版 `0.1.0` 上传成功。用户已在微信公众平台将它设为体验版，并生成了有效至 11 月 30 日前的体验码。体验成员权限由微信公众平台管理。

首页包括个人简介和三部精选作品：《空篷船》《千钧智勇》《非遗里的年味儿》。详情页显示封面与作品信息，并支持小程序分享入口。当前 `content.js` 中的 `media` 为空。接入已授权的原画播放地址后，在微信真机上检查起播、全屏及进度条拖动。

体验码、微信登录信息、本地私有项目设置和原画音视频不随源码同步。
